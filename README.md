## 环境与启动

使用 Python 3.12 和 uv：

```powershell
uv sync --locked
uv run python -m nongshi.check_env
uv run streamlit run src/nongshi/app.py
```

浏览器打开终端显示的本地地址。没有真实档案且未指定模式时，先显示一块已建立、已采用计划的模拟地块；模拟天气和现场条件都明确标注，记录写入独立模拟数据库。点击左栏“开始真实使用”进入空白建档卡片：填写名称即可保存，其他已知信息可展开补充；保存后进入桌面三栏工作台或窄屏页签。已有真实档案时默认返回真实工作台；地址中的 `?mode=demo` 或 `?mode=real` 可固定进入对应空间，切换模式后刷新也会保留选择。模拟示例过期时可在顶栏模式菜单中新建示例，旧记录不会被覆盖。随后可补充每日现场与天气确认、任务时长和可用时段，再生成计划预览。逐日资源需要分别确认；批量填写只修改选中的日期，范围外的未知值保持未知。计划只有在点击“采用这版安排”后才进入历史。编辑窗中的未保存内容在关闭窗口或切换地块后仍保留在当前页面会话，可继续编辑或主动放弃；这份临时缓存不保证刷新浏览器后仍在。

保存地块后，工作台以“今日执行台＋七天日期条”呈现当前安排，可切换整周清单；每张任务卡可查看本次目的、执行步骤、记录项和完成标准。支持单次任务、指定日期及固定间隔的周期巡田，也支持自定义现场或非现场待办；任务周期以稳定实例 ID 保存，编辑后续安排不会覆盖已完成记录。缺项优先补充一项，也可先查看部分计划。未采用计划时会说明暂无可执行日程，采用后才出现导出入口。窄屏默认打开“安排”页签，可切换到地块资料或助手。实现进度及未完成项见 [STATUS.md](STATUS.md) 与[本轮工作台报告](reports/workbench_v4_implementation_20261026.md)。

打开旧版 SQLite 计划库时，工作台会在增量建表前于同目录创建 `<数据库名>.pre-open-ga.bak`；再次打开不会覆盖这份备份。旧 v1/v2 计划继续只读，重新使用时复制输入创建新计划，不为旧记录补造未知事实或执行内容。个人数据库及备份均应留在仓库外；可用 `NONGSHI_DATABASE_PATH` 指向独立测试库。

已采用计划的任务详情可记录完成、明确更正或撤回误报完成、修改日期/时长/优先级，以及带原因取消未完成任务。更正保留原事实事件，任务修改和取消先保存输入再生成预览，仍需点击“采用这版安排”。历史版本可查看完整七天安排与差异；恢复旧版只按当前事实重算一份预览，不直接覆盖当前采用版。页面也会列出最多三条待补信息，并允许暂时跳过。助手展示实际模型与工具阶段，失败时可重试或改用结构化表单；退出等待后不再写入本轮迟到结果。助手提出的修改先保存为待确认草稿；刷新后可恢复。用户确认反馈后先保存事实并自动生成调整预览；若计算失败，可重试预览而不重交事实。可切换地块并导出 Markdown 清单或 JSON。

沟渠维护另外需要确认现场问题、维护需求及“清理既有沟渠”的目的。目的未知会保留待确认；开挖、加深、尺寸改造不在本版范围。已完成事项再次出现新问题时保留旧完成记录，以关联的新任务处理。

每一天可录入多个时段，以分号分隔，例如 `09:00-11:00;13:00-15:00`。相邻时段自动合并，重叠时段会提示错误。排程按单人连续作业计算，不会统筹其他地块的人员资源。默认计划从北京时间明天起算七天；选今天时仅使用未来时段。

## 天气与模型配置

天气使用 Open-Meteo 地名搜索和七天预报。湖北省离线搜索索引包含 GeoNames 中国地名数据，按 CC BY 4.0 发布；该索引是搜索辅助数据，不是官方行政区划或田间位置核验。系统结合行政区上下文排序候选点，仍需用户选择；县级查询点会明确标记，无法核实上级行政关联时不会擅自选择县级兜底点。天气快照保存请求位置、返回网格、单位、来源、时间和覆盖日期，并缓存六小时。缺日期或过期数据不会替代现场确认。

若本机系统代理导致天气接口出现 TLS 连接错误、而直连可用，可在启动应用的 PowerShell 会话中设置 `$env:NO_PROXY="open-meteo.com,.open-meteo.com"`；这只让天气请求绕过系统代理，模型请求仍按系统代理设置访问。

将 `.env.example` 复制为 `.env`，在本机填入新生成的 DeepSeek API 密钥。默认模型为 `deepseek-flash`，接口地址可通过 `NONGSHI_LLM_BASE_URL` 覆盖。密钥不要提交或贴到聊天记录。模型只能调用本地校验过的读取、检索、天气和计划预览工具；档案或事实修改须经用户确认。模型不可用时可继续使用结构化表单。

应用数据保存在 Git 忽略的 `data/local/plans.sqlite3`。设置 `NONGSHI_DATABASE_PATH` 可更改路径；独立模拟示例使用旁路数据库，避免混入真实地块。需要指定无 URL 参数时的初始空间，可设 `NONGSHI_DEFAULT_MODE=real` 或 `demo`；URL 的 `mode` 参数优先。旧版计划保留只读，并可明确复制为新草稿；未知信息不会被补造。
