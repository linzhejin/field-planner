# 农时窗口

农时窗口为油菜苗期提供农事规划。工作台支持空白建档、规则依据检索、Open-Meteo 天气风险查询、七天分钟级排程、现场事实记录、计划差异预览与用户确认采用。DeepSeek 可通过本地配置接入；未配置密钥时仍可使用完整的结构化操作。

七张候选规则 C11、C18、C19、C20、C23、C24、C31 仅供开发验证，适用性仍待复核。规则原文与来源指纹用于追溯，程序只执行明确实现的判断。天气预报只用于风险展示，不自动代表现场可作业。每份计划都注明尚未统筹其他地块时间；通过模拟测试不等于农艺验证或独立评测。

2026-10-21 七卡 AI 辅助复核原包及指纹见[归档入口](任务落实_20261020/李思默/第三步_七卡独立复核_20261021/README.md)。证据复核资料已交付，工程接入已按该结论修正；这不等于李本人盲法亲阅或正式采用签认。C11、C31 仅限观察记录，C23 仅限有明确现场问题、清理既有沟渠目的和维护需求的候选；C18、C19、C20、C24 仅作暂缓参考。来源原文、指纹、`runtime_enabled` 均未改写。引用用途、来源背景和项目限制由 `src/nongshi/data/rule_source_context.json` 显式登记，检索、任务、模型工具和导出共用。

当前产品口径见 [`产品设计v1/`](产品设计v1/)，团队任务和负责人以 [`任务清单_20261018_2.51am/`](任务清单_20261018_2.51am/) 的 V2.0 文件为准。`AIC claude code/` 保存早期项目说明、2026-10-16 任务清单及官方附件，作为历史资料，不与现行清单并行维护。

## 环境与启动

使用 Python 3.12 和 uv：

```powershell
uv sync --locked
uv run python -m nongshi.check_env
uv run streamlit run src/nongshi/app.py
```

浏览器打开终端显示的本地地址。首页从空白地块开始；保存档案后可补充每日现场与天气确认、任务时长和可用时段，再生成计划预览。计划只有在点击“采用这版安排”后才进入历史。助手提出的修改先保存为待确认草稿；刷新后可恢复。用户确认反馈后先保存事实并自动生成调整预览；若计算失败，可重试预览而不重交事实。可切换地块、查看历史版本并导出 Markdown 清单或 JSON。

沟渠维护另外需要确认现场问题、维护需求及“清理既有沟渠”的目的。目的未知会保留待确认；开挖、加深、尺寸改造不在本版范围。已完成事项再次出现新问题时保留旧完成记录，以关联的新任务处理。

每一天可录入多个时段，以分号分隔，例如 `09:00-11:00;13:00-15:00`。相邻时段自动合并，重叠时段会提示错误。排程按单人连续作业计算，不会统筹其他地块的人员资源。默认计划从北京时间明天起算七天；选今天时仅使用未来时段。

## 天气与模型配置

天气使用 Open-Meteo 地名搜索和七天预报。湖北省离线搜索索引包含 GeoNames 中国地名数据，按 CC BY 4.0 发布；该索引是搜索辅助数据，不是官方行政区划或田间位置核验。系统结合行政区上下文排序候选点，仍需用户选择；县级查询点会明确标记，无法核实上级行政关联时不会擅自选择县级兜底点。天气快照保存请求位置、返回网格、单位、来源、时间和覆盖日期，并缓存六小时。缺日期或过期数据不会替代现场确认。

若本机系统代理导致天气接口出现 TLS 连接错误、而直连可用，可在启动应用的 PowerShell 会话中设置 `$env:NO_PROXY="open-meteo.com,.open-meteo.com"`；这只让天气请求绕过系统代理，模型请求仍按系统代理设置访问。

将 `.env.example` 复制为 `.env`，在本机填入新生成的 DeepSeek API 密钥。默认模型为 `deepseek-flash`，接口地址可通过 `NONGSHI_LLM_BASE_URL` 覆盖。密钥不要提交或贴到聊天记录。模型只能调用本地校验过的读取、检索、天气和计划预览工具；档案或事实修改须经用户确认。模型不可用时可继续使用结构化表单。

应用数据保存在 Git 忽略的 `data/local/plans.sqlite3`。设置 `NONGSHI_DATABASE_PATH` 可更改路径；独立模拟示例使用旁路数据库，避免混入真实地块。旧版计划保留只读，并可明确复制为新草稿；未知信息不会被补造。
