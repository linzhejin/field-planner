# 农时窗口

农时窗口为油菜苗期提供单地块农事规划。当前工作台支持空白建档、规则依据检索、Open-Meteo 天气风险查询、七天分钟级排程、现场事实记录、计划差异预览与用户确认采用。DeepSeek 可通过本地配置接入；未配置密钥时仍可使用完整的结构化操作。

七张候选规则 C11、C18、C19、C20、C23、C24、C31 仅供开发验证，适用性仍待复核。规则原文与来源指纹用于追溯，程序只执行明确实现的判断。天气预报只用于风险展示，不自动代表现场可作业。每份计划都注明尚未统筹其他地块时间；通过模拟测试不等于农艺验证或独立评测。

## 环境与启动

使用 Python 3.12 和 uv：

```powershell
uv sync --locked
uv run python -m nongshi.check_env
uv run streamlit run src/nongshi/app.py
```

浏览器打开终端显示的本地地址。首页从空白地块开始；保存档案后可补充每日现场与天气确认、任务时长和可用时段，再生成计划预览。计划只有在点击“采用这版安排”后才进入历史。现场反馈先保存为事实，重算失败也不会丢失。可切换地块、查看历史版本并导出 Markdown 清单或 JSON。

每一天可录入多个时段，以分号分隔，例如 `09:00-11:00;13:00-15:00`。相邻时段自动合并，重叠时段会提示错误。排程按单人连续作业计算，不会统筹其他地块的人员资源。默认计划从北京时间明天起算七天；选今天时仅使用未来时段。

## 天气与模型配置

天气使用 Open-Meteo 地名搜索和七天预报。搜索结果需由用户选择；县级查询点会明确标记。天气快照保存请求位置、返回网格、单位、来源、时间和覆盖日期，并缓存六小时。缺日期或过期数据不会替代现场确认。

若本机系统代理导致天气接口出现 TLS 连接错误、而直连可用，可在启动应用的 PowerShell 会话中设置 `$env:NO_PROXY="open-meteo.com,.open-meteo.com"`；这只让天气请求绕过系统代理，模型请求仍按系统代理设置访问。

将 `.env.example` 复制为 `.env`，在本机填入新生成的 DeepSeek API 密钥。默认模型为 `deepseek-flash`，接口地址可通过 `NONGSHI_LLM_BASE_URL` 覆盖。密钥不要提交或贴到聊天记录。模型只能调用本地校验过的读取、检索、天气和计划预览工具；档案或事实修改须经用户确认。模型不可用时可继续使用结构化表单。

应用数据保存在 Git 忽略的 `data/local/plans.sqlite3`。设置 `NONGSHI_DATABASE_PATH` 可更改路径；独立模拟示例使用旁路数据库，避免混入真实地块。旧版计划保留只读，并可明确复制为新草稿；未知信息不会被补造。
