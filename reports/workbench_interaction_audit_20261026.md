## 验收标准

- 1158×714 与 1440×900 桌面布局保持三栏边界稳定，右侧输入区可见。
- 390×844 显示三个移动页签，文档无横向溢出，长文字不越出卡片。
- 保存、取消、重试和历史/导出操作有明确结果；异常不泄露英文堆栈，不丢弃未保存输入。
- 按钮操作后无空白页、栏位塌缩或未捕获异常；开发者控制台无错误和警告。

## 发现与处理

| 问题 | 结果 |
| --- | --- |
| 编辑地块后显式放弃，输入仍显示为未保存内容 | 已修复：放弃时清除编辑缓存、切换控件代次并完整刷新；按钮在内容变更的同次刷新中出现。重新打开后回到已保存值。 |
| 现场观察快捷表单没有取消入口，成功后表单仍保持打开 | 已修复：观察、完成、资源变更表单增加“取消填写”；取消不写入事实并重置未提交控件。保存成功后清除快捷表单状态。 |
| 三栏在 Streamlit 刷新时高度变化 | 已处理：桌面面板固定高度，栏内独立滚动。1158×714 点击过程中三栏保持 613px；1440×900 三栏保持 799px。 |
| 地块保存抛出 SQLite 或其他运行时异常 | 已修复并复验：设置本地写入等待上限，分类捕获 SQLite、校验和未预期异常；失败保留已填内容并给出中文重试提示。模拟数据库锁定时能看到错误提示，解除锁定后重试保存成功。 |

| 待确认任务说明跑出卡片边框 | 已修复：任务卡内 Streamlit caption 默认 `-16px` 下边距压缩容器；改为卡内 `0px`。实测 1158px 与 390px 的任务说明均完整落在卡片内。 |
| 助手空闲时输入框周期性重绘 | 已修复：原来闲置时仍每 0.5 秒运行助手进度片段，2.2 秒内观测到 32 次输入区 DOM 属性变更；现仅在有活动助手任务时挂载轮询片段，修复后同样 2.2 秒观测为 0 次变更。 |
