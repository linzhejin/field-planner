# 七天任务与工作台优化实施记录

日期：2026-10-26（北京时间）
实现分支：`codex/weekly-task-content`，基于 `509da4c`；交付提交 `63ba137` 已合入本地 `main` 并推送至 GitHub `main` 与 Gitee `master`。本报告记录本轮实现与检查，不继承 v12 冻结评测分数。

## 已实现

- 新增版本化任务模板、周期定义与稳定任务实例，支持单次、多个指定日期和固定间隔；重启和跨周查询沿用实例 ID。编辑周期只更新后续未完成实例，完成、取消和执行结果保留历史快照。
- 把 v4 实例接入现有分钟级排程与前置关系。加入“尽早、均衡、集中”偏好；非现场待办不要求田间作业条件，现场任务仍按已确认条件处理。计划快照更新为 v4，旧版计划仍按只读方式兼容。
- 增加任务目的、触发原因、步骤、结果记录项、完成标准、后续动作和来源状态。任务详情按执行顺序呈现；结果字段区分正常、发现问题、无法判断和未检查。
- 增加问题记录及来源关联、维护和复查任务关联。重复观察关联已有未解决问题；关闭问题需确认解决，重复出现的问题建立新记录并保留旧记录。
- 增加自定义现场/非现场待办，并让其进入相同排程。Agent 可形成自定义任务提案；用户确认后保存，再生成预览，不直接采用安排。
- 工作台增加“今日执行台＋七天日期条”、整周清单、空白日期状态、预计工作量、单次任务操作和周期编辑入口；增加互相隔离的稀疏与任务丰富演示数据。等待确认提案或预览时，主操作层级不会与新增任务表单冲突。
- 增加用户确认的合并出行执行组：巡田与问题复查共享一次外出时段和总耗时，成员任务分别保存结果；成员或任务内容变化后需要重新确认，取消分组会释放未完成成员。
- 修复完成组内一项后兄弟任务失去时段、同一任务进入多个未取消分组、跨地块复用分组编号覆盖归属，以及完成成员的历史时段与改期后新时段错误去重的问题。已完成成员的历史占时只计一次，未完成成员仍须通过当前现场/天气条件检查。
- SQLite 采用增量表，迁移前备份并允许重复初始化；已有表和计划保留。
