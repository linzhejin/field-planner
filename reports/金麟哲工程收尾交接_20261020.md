## B04 / B06 可复现验收清单

运行环境：仓库根目录，Python 3.12 + uv，`.env` 内含有效 DeepSeek 密钥。

```powershell
uv sync --locked
uv run python -m nongshi.check_env
uv run streamlit run src/nongshi/app.py
```

固定输入（验收时逐项核对）：

- 地块：名称任填；地区 湖北、已确认；作物 油菜、已确认；生育期 苗期、已确认。
- 田型：低洼/稻茬田；田型事实（稻茬/冷浸/地形）任填并保存。
- 巡田需求：是；预计分钟数 30。
- 观察：沟渠连通情况「受阻」、积水情况「是」、是否有实际降雨「否」。
- 七天：每日现场与天气均选「可作业」，可用分钟数 120，时段 `09:00-11:00`。

逐项预期：

1. 候选事项页显示巡田任务；维护任务在未确认问题/需求前为「待确认」并列出缺项。
2. 「规则依据与来源」展开后可见 C11/C31/C23 原文、页码、限制与指纹；暂缓卡显示为历史参考并带 A04 补充来源前缀。
3. 存在积水记录时页面出现现场核实/联系农技人员提示，且无任何阈值或「24 小时」字样。
4. 预览并「采用这版安排」后，导出 Markdown 含「单地块；尚未统筹其他地块时间」「依据」「任务」；导出 JSON 含 `schema_version=3`、`adopted_plan`、`history`。
5. 记录一项巡田完成为「已完成」，刷新后仍保留；对同一任务重复提交完成被拒绝且不产生新版本。
6. 关闭应用重开，草稿、事实与已采用计划一致；未知项保持未知，不被补造。

请许继哲按上述输入实际操作页面并记录界面结果；我方提供的是稳定版本、输入与保存回读证据，不代替页面验收结论。
